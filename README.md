# 🎵 K-Pulse News — Blog de Notícias de K-Pop

O **K-Pulse News** é um portal de notícias moderno, responsivo e visualmente impactante voltado para a cultura K-Pop. O layout foi desenvolvido em estilo *Dark Mode* vibrante, utilizando tons de roxo, rosa neon e azul para proporcionar uma estética imersiva típica da cultura pop coreana.

---

## 📌 Conteúdo em Destaque

- **Polêmica BTS (RM e J-Hope):** Matéria cobrindo a repercussão e debates no fandom (ARMY) sobre a presença dos integrantes no show do cantos Chris Brown em Toronto.
- **BLACKPINK 10 Anos:** Artigo comemorativo sobre a marca de uma década de debut do grupo da YG Entertainment e celebrações com os BLINKs.
- **Seção "Mais Lidas" & Newsletter:** Sidebar interativa para retenção de usuários e captura de e-mails.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica de tags (`<header>`, `<main>`, `<article>`, `<aside>`, `<footer>`).
- **CSS3:** Variáveis globais (`:root`), Flexbox, CSS Grid, animações de transição no hover e media queries.
- **Google Fonts:** Tipografia *Poppins* (pesos 300, 400, 600 e 700).

---

## 📐 Recursos de Front-End

1. **Design Responsivo:** Layout adaptável para telas desktop, tablets e smartphones.
2. **Header com Transparência (Blur):** Efeito de desfoque ao rolar a página utilizando `backdrop-filter`.
3. **Cards Dinâmicos:** Microinterações ao passar o mouse com sombras em rosa neon.
4. **Sem Dependências Externa de Build:** Código puro e leve rodando diretamente no navegador.

---

## 🚀 Como Rodar o Projeto

1. Baixe ou copie o código do arquivo `index.html`.
2. Abra o arquivo `index.html` em qualquer navegador web (Chrome, Firefox, Edge, Safari).
3. Não requer instalação de pacotes ou servidores local.
